# 加油（加气）站利润计算器小程序版

当前本地版本：`1.3.1`

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`wechat-miniprogram`。
4. AppID 填写你已经认证通过的小程序 AppID。
5. 打开后点击“编译”，即可预览。

## 当前说明

- 计算逻辑按当前 H5 版本迁移。
- 本版增加可选 LNG 加气业务：销量按公斤/天录入、报告按吨展示，默认毛利 0.50 元/公斤，参考采购价 4000 元/吨、销售价 4500 元/吨。
- 共同费用默认按汽油:柴油:LNG = 3:1:1 分摊；LNG 按 9%增值税口径测算，并同步进入报告、简要分享图和完整报告图片。
- 土地/油站租金从管理费用中单独列示，分别显示各油气品类的吨油（或每公斤）管理费用和租金成本；租金相关信息使用暖红色突出显示。
- 油站资产流转服务更新了油站状态，并将需求类型“整体转让”调整为“整体转让（转租）”。
- H5 与小程序顶部统一使用正式小程序 Logo。
- 留言和油站资产流转登记在预览版会先保存在本机缓存。
- 正式上线收集客户信息时，建议接入云开发数据库，并在小程序后台配置隐私保护指引。
- 当前仅生成本地预览工程，尚未上传微信后台，也未提交审核。
