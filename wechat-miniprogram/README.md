# 加油（加气）站利润计算器小程序版

当前本地版本：`1.3.3`

## 1.3.3 版本备注

本版将小程序调整为纯粹的加油（加气）站利润计算器，删除“给作者留言”、油站资产流转登记及登记记录功能，不再收集或保存用户联系方式和油站流转信息。保留利润测算、完整报告、公式说明及图片分享功能；转发给朋友使用 5:4 展示卡片，分享到朋友圈使用小程序 Logo。新版首次打开时会自动清除旧版本留在本机的留言和登记数据。

## 使用方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹：`wechat-miniprogram`。
4. AppID 填写你已经认证通过的小程序 AppID。
5. 打开后点击“编译”，即可预览。

## 当前说明

- 计算逻辑按当前 H5 版本迁移。
- 本版增加可选 LNG 加气业务：销量按公斤/天录入、报告按吨展示，默认毛利 0.50 元/公斤，参考采购价 4000 元/吨、销售价 4500 元/吨。
- 共同费用默认按汽油:柴油:LNG = 3:1:1 分摊；LNG 按 9%增值税口径测算，并同步进入报告、简要分享图和完整报告图片。
- 土地/油站租金从管理费用中单独列示，分别显示各油气品类的吨油（或每公斤）管理费用和租金成本；租金相关信息使用暖红色突出显示。
- H5 与小程序顶部统一使用正式小程序 Logo。
- 开启右上角“转发给朋友”“分享到朋友圈”和复制链接能力，并设置统一分享标题与入口页面；好友和群聊分享使用 5:4 专用展示卡片，朋友圈使用小程序 Logo。
- 删除给作者留言、油站资产流转登记和登记记录功能，程序仅保留利润计算、报告、公式说明与图片分享；首次打开会清除旧版本留在本机的相关信息。
- 当前仅生成本地预览工程，尚未上传微信后台，也未提交审核。
